# FOT10 ⚽

FOT10 is a mobile-first football experience focused on fast scores, fixtures, live match tracking, teams, leagues and statistics.

## Vision

A polished Persian/English football companion with a premium, fast interface and a clean architecture ready for real sports-data integration.

## Product pillars

- Live scores and match center
- Fixtures and results
- League tables and competitions
- Teams, players and favorites
- Match timeline and statistics
- Persian RTL + English LTR
- Dark mode
- Notification-ready architecture
- Responsive mobile-first UI

## Development

The first milestone focuses on the core product shell and a high-quality match experience. Demo data is intentionally labeled; real scores must come from a verified sports-data provider before production release.
